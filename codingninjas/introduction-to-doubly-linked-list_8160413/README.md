## Problem Statement

<h4 id="you-are-given-an-array-arr-of-size-n-consisting-of-positive-integers">You are given an array <strong><em>‘Arr’</em></strong> of size <strong><em>‘N’</em></strong> consisting of positive integers.</h4>

<p><br/></p>

<h4 id="your-task-is-to-make-a-doubly-linked-list-from-the-array-and-return-the-head-of-the-linked-list">Your task is to make a doubly linked list from the array and return the head of the linked list.</h4>

<p><br/></p>

<h4 id="here-the-head-of-the-doubly-linked-list-is-the-first-element-of-the-array-and-the-tail-of-the-doubly-linked-list-is-the-last-element">Here, the head of the doubly linked list is the first element of the array, and the tail of the doubly linked list is the last element.</h4>

<p><br/></p>

<h5 id="note">Note:</h5>

<pre><code>A doubly linked list is one in which it is possible to access the next and the previous nodes from a node in the linked list (if they exist).
</code></pre>

<p><br/></p>

<h5 id="example">Example:</h5>

<pre><code>Input: ‘N’ = 4, ‘Arr’ = [4, 2, 5, 1]

Output: 4 2 5 1

Explanation: Doubly Linked List for the array ‘Arr’ = [4, 2, 5, 1] is 4 &lt;-&gt; 2 &lt;-&gt; 5 &lt;-&gt; 1.
</code></pre>

<p><br/></p>

<h5 id="input-format">Input Format</h5>

<pre><code>The first line contains one integer, ‘N’, denoting the size of the array ‘Arr’.

The following line contains ‘N’ integers, denoting the ‘Arr’.
</code></pre>

<p><br/></p>

<h5 id="output-format">Output format:</h5>

<pre><code>Return the head of the doubly linked list.
</code></pre>

<p><br/></p>

<h5 id="note">Note:</h5>

<pre><code>You don&#39;t need to print anything. Just implement the given function. Contents of your returned doubly linked list will be printed. 
</code></pre>

<pre><code>4
4 2 5 1

<h5 id="sample-output-1">Sample Output 1 :</h5>

Explanation: 
Doubly Linked List for the array ‘Arr’ = [4, 2, 5, 1] is 4 &lt;-&gt; 2 &lt;-&gt; 5 &lt;-&gt; 1.
